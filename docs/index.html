3 Methods to Install / Flash

SL6801's bootloader (301a:2800) uses USB Mass Storage (class 0x08), which browsers block from direct WebUSB. Pick any of the 3 methods below:

Enter Bootloader Mode: Power player completely off → hold Volume Up → plug in USB-C.
After Flashing: Unplug USB → hold Power 10s (release) → hold Power 3s to boot.
Download sl6801_ipod.bin (2 MB) View Repo on GitHub 
git clone https://github.com/fp101fs/sl6801-ipod.git
cd sl6801-ipod

# 1. Back up your stock firmware first
sudo ./smartlink_flash/smtlink_dump init read_flash 0 2M firmware/my_stock_backup.bin

# 2. Flash iPod Classic firmware (verifies FIRM CRC16)
sudo ./scripts/flash_ipod.sh
Windows: Install WinUSB for 301A:2800 with Zadig, then run smtlink_dump.exe init write_flash 0 0 0 firmware/sl6801_ipod.bin.

Start the tiny local Python bridge so this page can back up, flash, and verify your SL6801 directly from your browser: 

sudo python3 scripts/flash_bridge.py

Tip: On macOS/Linux, smtlink_dump needs sudo to detach the OS mass-storage driver.
