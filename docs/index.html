Install on Your SL6801

GitHub Repo

Choose whichever of the 3 install methods fits your workflow. Always back up your stock 2 MB flash first.

Before Flashing (Bootloader) Power player off, hold Volume Up, then plug in USB-C.
After Flashing (Reboot) Unplug USB, hold Power 10s, release, then hold Power 3s.

Clone the repo and run the verified flash script (macOS & Linux), or download the 2 MB firmware image directly.

Download sl6801_ipod.bin (2 MB) 
git clone https://github.com/fp101fs/sl6801-ipod.git
cd sl6801-ipod

# 1. Back up your stock firmware
sudo ./smartlink_flash/smtlink_dump init read_flash 0 2M firmware/my_stock_backup.bin

# 2. Flash iPod Classic firmware & verify CRC16
sudo ./scripts/flash_ipod.sh

Windows: Install WinUSB for 301A:2800 via Zadig, then run smtlink_dump.exe init write_flash 0 0 0 firmware/sl6801_ipod.bin.

Browsers block direct WebUSB on Mass Storage (0x08) bootloaders. Start this tiny local bridge to back up and flash right from this page: 

sudo python3 scripts/flash_bridge.py
