3 Ways to Install.

Back up your stock 2 MB flash, then flash with Manual CLI, Web Flash, or an LLM prompt.

🥾 Enter Bootloader Mode (301a:2800)
  • Unplug USB-C
  • Power off completely
  • Hold Volume Up (+)
  • Plug in USB-C
  • Wait a few seconds

(the screen will stay powered off — if you want to check if it's connected, ask your CLI AI agent!)

⚡ Reboot After Flashing
  • Unplug USB-C
  • Hold Power for 10s, then release
  • Hold Power for 3s to boot
  1. Put SL6801 into Bootloader mode (see 🥾 above).
  2. Clone the repository, back up your stock 2 MB flash, and flash sl6801_ipod.bin: 
    git clone https://github.com/fp101fs/sl6801-ipod.git
cd sl6801-ipod

# Back up stock 2 MB flash first
sudo ./smartlink_flash/smtlink_dump init read_flash 0 2M firmware/my_stock_backup.bin

# Flash iPod Classic firmware & verify FIRM CRC16
sudo ./scripts/flash_ipod.sh
    Windows: Install WinUSB for 301A:2800 with Zadig, then run smtlink_dump.exe init write_flash 0 0 0 firmware/sl6801_ipod.bin.
  3. Reboot your SL6801 (see ⚡ above).
